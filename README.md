# Weather-Based Music Recommender 🌦️🎵

A dynamic, location-aware application that seamlessly integrates weather data with music curation. By fetching the user's real-time location and local weather conditions, the system automatically recommends a personalized 3-song playlist tailored to the current mood of the weather, complete with direct links to listen on YouTube Music for free.

### 🎯 Core Features & Logic
- **Geolocation Integration:** Automatically detects the user's current geographic location.
- **Real-Time Weather Data:** Communicates with external Weather APIs to fetch accurate, up-to-the-minute local weather conditions.
- **Dynamic Recommendation Engine:** Uses a custom logic mapping system to pair specific weather patterns (e.g., rainy, sunny, cloudy) with appropriate musical genres and tracks.
- **Seamless Streaming:** Generates actionable links that redirect users directly to YouTube Music to play the recommended tracks instantly.
